TechGear - Web Technology Lab Project

TechGear is a simple and responsive e-commerce website for a computer accessories shop. This project was developed as part of a Web Technology Lab to demonstrate the practical implementation of HTML, CSS, JavaScript, and Bootstrap in a multi-page website.

📌 Project Overview

The website provides a clean and user-friendly interface where users can browse different computer accessories, explore product categories, view special offers, and learn more about the TechGear store.

The project consists of multiple interconnected web pages with a consistent navigation bar and design throughout the website.


**Features**

🏠 Home Page - Introduces the TechGear store and highlights popular products.

🛍️ Products Page - Displays available computer accessories with descriptions and prices.

📂 Categories Page - Organizes products into categories such as:

Keyboards

Mouse

Audio

Camera

**Offers Page - Displays special discounts and promotional offers.

About Page - Provides information about TechGear and its services.

JavaScript Interaction - Includes a welcome message triggered from the home page.

Responsive Layout - Uses Bootstrap's grid system to create a responsive structure.

Custom Styling - Uses a separate CSS file for the website's appearance and layout.**



**Technologies Used**

HTML5 - Used to structure the web pages.

CSS3 - Used for custom styling and page layout.

JavaScript - Used to add basic interactivity.

Bootstrap 5.3.3 - Used for responsive design and UI components.

**How to Run the Project**

Download or clone this repository.

Open the project folder.

Double-click index.html to open the website in a web browser.

Use the navigation menu to explore the different pages.

No server or database is required to run this project.



**Academic Purpose**

This project was created for a Web Technology Lab to demonstrate fundamental concepts of front-end web development, including:

Creating structured web pages with HTML

Designing layouts using CSS

Using Bootstrap for responsive web design

Linking multiple web pages together

Adding basic JavaScript functionality

Creating a consistent and user-friendly website interface
